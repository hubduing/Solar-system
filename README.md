# SOLAR SYSTEM M42 — Тактический стол Инквизиции

Интерактивная карта Солнечной системы в стилистике Warhammer 40000 (M42).
Не научная модель, а голографический стол: мрачная палитра, готический HUD, свет Астрономикона в центре.

Живая версия (после настройки Pages): `https://hubduing.github.io/Solar-system/`

## Возможности

- **Реестр объектов (левая панель)** — сворачиваемый список всех тел + Солнце, текстовый фильтр по имени/миру/фракции, счётчик `найдено / всего`. Клик центрирует камеру и открывает досье — попадать курсором по мелким телам не нужно.
- **Досье (правая панель)** — клик по телу или точке роя, поиск, фильтры 5 фракций, кнопка `EXTERMINATUS` (взрыв + кольцо + удаление тела).
- **Время Инквизитора** — пауза, скорости x1 / x10 / x100. Горячие клавиши: `Space`, `1/2/3`.
- **Рой до 30к** — пояса астероидов, мусор, караваны, патрули, Хаос, Тираниды на `Float32Array`, батчевая отрисовка, culling + LOD. Переключение 7к / 10к / 30к в шапке, `?swarm=` в URL.
- **Атмосфера M42** — 5 туманностей, 3 варп-разлома, обломки Кадии (260), 6 халков, поля Геллера (Терра, Юпитер, Сатурн).
- **Камера** — drag-панорама, wheel-зум к курсору, dblclick / `R` — сброс, `+` / `−` в шапке, FPS-счётчик.

## Управление

| Действие | Как |
|---|---|
| Панорама / зум / сброс | drag · wheel · dblclick / R |
| Досье без прицеливания | левый «РЕЕСТР» → клик по строке |
| Досье прицеливанием | клик по телу / точке роя на канвасе |
| Пауза / скорость | кнопки в шапке или `Space` / `1` / `2` / `3` |
| Фракции | чекбоксы справа (прячут рой, тела, орбиты) |
| Рой 7к / 10к / 30к | кнопки в шапке |

## Запуск и сборка

```bash
npm install
npm run dev      # локально
npm run build    # прод-сборка в dist/
npm run preview  # просмотр сборки
```

Деплой на GitHub Pages (статика):

```bash
npx gh-pages -d dist
```

В `vite.config.js` задан `base: '/Solar-system/'`. В настройках репозитория → Pages источником должна быть ветка `gh-pages`.

## Стек и структура

- React (Vite) — только HUD/UI. Симуляция и отрисовка — Canvas 2D вне React state (`useRef` + типизированные массивы).
- `src/components/SolarCanvas.jsx` — движок: rAF-цикл, камера, слои, хит-тест, LOD/culling, API (`focusBody`, `exterminatus`, `setSwarmCount`…).
- `src/App.jsx` + `src/App.css` — HUD: шапка, реестр слева, досье справа, футер.
- `src/data/bodies.js` — 10 именованных тел M42.
- `src/sim/swarm.js` — рой (`createSwarm` / `updateSwarm`).
- `src/sim/atmosphere.js` — туманности, разломы, Кадия, халки, Геллер.

Подробный план по шагам — в `PLAN.md`.
