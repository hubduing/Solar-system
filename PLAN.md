# Solar System M42 — План проекта

## Концепция
Интерактивная карта Солнечной системы в стиле Warhammer 40000 (M42).
Не научная модель, а тактический голографический стол Инквизиции: мрачная палитра, готический HUD, свет Астрономикона в центре.

## Стек (финальный)
- **React (Vite)** — только HUD/UI: панели, досье, фильтры, управление временем.
- **Canvas 2D** — вся симуляция и отрисовка. Объекты НЕ в React state, только в `useRef` + типизированные массивы.
- **GitHub Pages** — только статика (`npm run build` + деплой). Go/бэкенд исключен.

Причина: React-DOM умирает на 30-50к объектов, Canvas + `Float32Array` тянет тысячи/десятки тысяч.
